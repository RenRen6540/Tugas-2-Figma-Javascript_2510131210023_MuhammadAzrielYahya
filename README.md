# Tantamount! Fauna Nusantara
Game memory (mencocokkan kartu) bertema hewan khas Indonesia. Setiap pasangan yang cocok menampilkan fakta singkat hewan tersebut.

# Fitur utama
1. Ada 3 tingkat kesulitan (Mudah, Sedang, Sulit) denga batas waktu yang berdeda-berbeda.
2. Skor dengan bonus kombo dan bonus sisa waktu.
3. Tombol intip (2x, dengan penalti skor), jeda, dan ulang.
4. Papan skor per tingkat, tersimpan di localStorage.
5. Responsif (Desktop dan Mobile) dan bisa dimainkan dengan keyboard.

# Cara menjalankan
1. Unduh folder ini.
2. Buka 'index.html' di browser. Tidak perlu instalasi.

# Live demo (GitHub Pages)
Upload ke repositori GitHub, lalu aktifkan di Settings, lalu ke bagian Pages, dan Branch 'main' atau root.

# Teknologi
HTML5 semantik, CSS (Flexbox, Grid, Media Queries), JavaScript (DOM, event, Array of Objects, arrow function).
